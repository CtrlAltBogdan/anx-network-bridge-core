# ANX Network Bridge Core

[English](README.md) · Русский

Платформонезависимая часть ANX Network Bridge — официального агента [anx.run](https://anx.run) для Minecraft-сетей:
HTTP-клиент, очередь на время недоступности API, подключение, телеметрия, награды за голоса и диагностика. Без зависимостей.

Плагин здесь не собирается. Плагины:

- [anx-network-bridge-velocity](https://github.com/CtrlAltBogdan/anx-network-bridge-velocity)
- [anx-network-bridge-bungee](https://github.com/CtrlAltBogdan/anx-network-bridge-bungee) (BungeeCord и Waterfall)
- [anx-network-bridge-paper](https://github.com/CtrlAltBogdan/anx-network-bridge-paper)

## Как плагины используют ядро

В каждом репозитории плагина лежит копия этих исходников в `core/` на точном теге. Тег, его коммит и SHA-256 дерева
записаны в `core.lock`. Сборка плагина падает, если `core/` отличается от записи, а CI сверяет запись с этим репозиторием.
Новое ядро попадает в плагин только отдельным коммитом (`scripts/update-core.sh <тег>`), поэтому изменение ядра не может
незаметно изменить уже выпущенный плагин.

## Какие данные передаются

Телеметрия содержит общее число игроков, состояние режимов и разрешённые имена внутренних серверов.
Ники, UUID, IP-адреса игроков и сообщения чата в неё не входят. Для наград используется отдельный API:
плагин получает ник проголосовавшего игрока и выполняет команды, заданные владельцем сервера.

Ключ подключения хранится локально в `agent.key`. Не добавляйте этот файл в Git и не прикладывайте его к сообщениям
об ошибках. Ядро использует стандартную библиотеку Java и не включает сторонний HTTP- или JSON-фреймворк.

## Сборка и проверка

```sh
./gradlew clean build
```

Нужна Java 21; Wrapper закрепляет Gradle 9.9.2 и проверяет его SHA-256. Сборка идёт с `-Xlint:all -Werror` и запускает
самотест, включая полный прогон агента против локальной замены API.
